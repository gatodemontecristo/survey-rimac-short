## About The Project

![image](https://github.com/user-attachments/assets/ecdc04aa-f5d4-4c4a-85c9-4b27f6fa91d5)

Survey Rimac Short 2025 is a dynamic and interactive web application designed to streamline the process of collecting user information through a series of slides and forms. Built with modern web technologies such as React, TypeScript, and Framer Motion, the project provides a seamless and visually appealing user experience. The application is tailored for Rimac, focusing on user engagement and efficient data collection.

## Requirements

Before starting, ensure you have the following installed on your system:

* Node.js: Version 20.x or higher. Download it from <a href="https://nodejs.org/en">Node.js</a>.
* Yarn: Version 1.22 or higher.
  
  ```sh
  npm install -g yarn
  ```
* Git: To clone the repository. Download it from <a href="https://git-scm.com/">Git</a>.

## Installation Steps

Follow these steps to install and run the project locally:

* Clone the repository: Clone the repository from GitHub to your local machine:
  
   ```sh
  git clone https://github.com/gatodemontecristo/survey-rimac-short.git
  cd survey-rimac-short
  ```
* Install dependencies: Install all the necessary dependencies using Yarn:
  
   ```sh
  yarn install
  ```
* Run the development server. Start the development server with Vite:

   ```sh
  yarn dev
  ```

## Additional Commands

The project includes several useful scripts that you can run with Yarn:

* Build for production:

 ```sh
  yarn build
  ```
* Build unit tests:

 ```sh
  yarn test
  ```
* Build Storybook:

 ```sh
  yarn storybook
  ```
